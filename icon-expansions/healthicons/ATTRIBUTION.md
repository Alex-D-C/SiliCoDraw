# Health Icons: attribution

**Source:** [Health Icons](https://healthicons.org), a volunteer project hosted by the public-health not-for-profit
Resolve to Save Lives, from its GitHub repository
[resolvetosavelives/healthicons](https://github.com/resolvetosavelives/healthicons) at commit
`2080c1b40e4829f2f4217e03bc22908b4e402f6b` (2026-11-04). The site's About page names Daniel Burka and Jahanvi Singh as
maintainers and lists the volunteer contributors; the repository names no creator per icon, so this pack names none.

**License:** CC0 1.0 Universal (public domain dedication), for every icon file ("The icons (the SVG and PNG files in
public/icons) and the npm packages ... are in the public domain under CC0 1.0 Universal", the repository's LICENSE).
The repository's MIT License covers only the code of the healthicons.org website. See `LICENSE.txt`.

**How Health Icons asks to be credited** (read on https://healthicons.org/licenses on 2026-11-14):

> The icons are in the public domain, so you can use them in any type of project, for free, with no credit needed.

Every page of the site adds: "Editing is ok. Republishing is ok. No need to give credit." So no credit is required, and
SiliCoDraw adds no credit line for these icons. Page → Copy full icon credits gives a line naming the library for
anyone who wants to mention it: *Health Icons (healthicons.org), CC0 1.0*.

**Origin of some drawings:** the About page says that "Some of these icons are based on open source icons in DHIS2 and
from Medic.org" (the project began by redrawing the icons of the open-source DHIS2 health software; many icons carry a
`dhis2:` tag in the repository's metadata). Health Icons publishes all of its icon files under CC0 as stated above; the
`dhis2:` ids are not used as search words here.

**What SiliCoDraw changed:** the SVG files were converted to SiliCoDraw's icon format with `dev/icon-import`, one style
only: the 48 px filled icons (solid pictograms, closest to SiliCoDraw's own flat icons and easiest to read at figure
size; the outline style draws the same subjects with thin lines, and the 24 px versions are the same subjects again on
a smaller grid). Each icon was fitted into a 100 × 100 box, its coordinates rounded and its one color (`currentColor`
in the original, drawn black) made recolorable. Every icon was drawn and compared with the original on a white and on
a dark page; all passed. One drawing that the repository has twice under two names (its rounded malaria rapid test
"PV Invalid" is drawn exactly as "PF") is in the pack once, and both names find it; so is the hand with a drop of blood that it has as "Diabetes" under People and again under Symbols (two files of one drawing that differ only in how its outline is written), whose words (DM, endocrinology, glucose, sugar) find the one kept. Names are the repository's titles, without the "ALT" of a
second drawing of a subject (numbered instead), in American spelling (Esophagus Cancer, Orthopedics, Person Traveler),
with typos corrected (Obstetrics, "Mixed Positive", Mosquitoes), the malaria rapid tests named "Rapid Diagnostic Test …" and the
rectangular cassettes marked so; the titles and tags remain search words. The groups in the Add panel are the
repository's categories.

**Left out:** the categories typography (letters, digits, currency signs) and shapes (plain circles, squares,
triangles and stars); logos and trademarks (DHIS2, Excel, OpenMRS, Simple.org, FHIR, HL7, LOINC, and the ICD, ICD-9,
ICD-10 and ICD-11 marks); user-interface symbols (question marks, plus and minus, check mark, cancel, stop, info and
alert circles, magnifying glass, menus, folders, settings, zoom and user-profile buttons, signal bars and 2G to 5G,
level bars, chat bubbles, location pin, QR code, camera, video, magic wand, a calendar with a clock, a document edit
and a cardiogram edit button, data sync, database, tally marks, a polygon, a peace sign, exam papers, a plain arrow
"referral" and an unlabeled "IMM" glyph); and the military tank of the vehicles. Brand names among the tags (Excel,
MacOS, Jeep) are not search words.
